# Grille d'évaluation du module

Le module « Renforcement Dev Web » se valide par deux livrables. Le premier est une mini-application web, versionnée avec Git : pour vous, c'est Cap Web. Le second est la documentation : un README qui permet d'installer, de lancer et de comprendre le projet, et le bilan individuel de chacun de vous deux.

Chaque ligne du tableau se regarde sur votre code, dans votre historique Git et à l'oral : chacun explique son code, éditeur fermé. Les cinq premières lignes concernent la mini-application, la dernière le README et le bilan. Chaque ligne reçoit un des trois niveaux : acquis, en cours ou à renforcer.

| Ce qui est regardé | Acquis | En cours | À renforcer |
|---|---|---|---|
| Structure HTML, CSS et JavaScript | La page est structurée, lisible sur téléphone, et vous savez expliquer chaque fonction | La page marche, mais une partie reste difficile à expliquer | La page ne marche pas, ou vous ne savez pas dire ce que fait le code |
| Interactions : le DOM et les événements | Un événement met la page à jour, le texte reste du texte, et vous savez dire quel code réagit | L'interaction marche, mais le chemin du code reste flou | L'interaction ne marche pas, ou elle injecte du HTML |
| Organisation du projet | Chaque module garde son rôle, et des tests vérifient le comportement | Des rôles se mélangent, ou les tests ne couvrent qu'une partie | Tout le code est au même endroit, ou aucun test ne tourne |
| Échange de données (J3) | La page demande des données avec fetch, lit le JSON et affiche un message clair en cas d'erreur | L'échange marche, mais l'erreur n'est pas traitée | Aucun échange de données, ou il bloque la page |
| Git | Des commits courts, chacun avec un message qui dit ce qui change, et le projet sur un dépôt distant (J3) | Des commits existent, mais gros ou avec des messages vagues | Peu de commits, ou un historique qu'on ne peut pas lire |
| README et bilan individuel | Une personne qui découvre le projet l'installe, le lance et le comprend ; le bilan de chacun dit, notion par notion, ce qui a progressé et ce qui reste à travailler | Le README ou le bilan est incomplet | Pas de README utilisable, ou pas de bilan |

Les points de jeu des rounds servent au podium du jour ; ils ne comptent pas dans l'évaluation du module.

Votre positionnement, en tête du carnet de J2, est votre point de départ. Le bilan individuel, en fin de module, dit ce qui a changé depuis.
